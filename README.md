## ⚡ Key Features

- **Photorealistic Rendering:** Ray tracing and global illumination for cinema-quality visual output.
- **Parametric Design:** Constraint-based modeling with full revision history and rollback support.
- **Material Library:** Extensive collection of physically accurate materials and shader presets.
